## Building systems people can trust

I’m a backend-first, full-stack software engineer based in Nigeria. I build APIs, SaaS products, and web applications with **Python** and **TypeScript**, then carry them through to clear, useful interfaces with **React** and **Next.js**.

My work centres on backend systems, databases, authentication, practical AI integrations, automated testing, Docker, and cloud deployments. I’m open to remote engineering roles, freelance projects, and well-scoped product work.
